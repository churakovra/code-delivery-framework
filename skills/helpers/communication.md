# Communication

Use when: Ambiguity-sensitive instructions or agent handoffs.

State one action per sentence. Name the actor, object, condition, and expected result when ambiguity matters. Use one name for each concept. Separate requirements from recommendations and observations from inferences. Preserve qualifiers such as “may” or “only when.” Keep paths, commands, and numbers exact. For handoffs, state ownership, acceptance, constraints, and evidence gaps. Check that another agent can act without guessing. Stop when the meaning is clear; do not enforce a dictionary or rewrite unrelated prose.
