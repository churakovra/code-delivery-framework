# Explanation foundation

Start with the user's goal and existing knowledge. Present the relevant big picture first, then narrow to the requested mechanism and a concrete example. Define unfamiliar terms as needed. Keep the answer proportional to the question while preserving necessary conditions and tradeoffs. Use a small, meaningful diagram when it clarifies relationships or flow; do not add one merely to include it.

For code, inspect enough surrounding behavior to explain the relevant flow. For structural questions, use Codebase Memory when available and suitable; read its skill when available, check freshness and coverage, verify material claims in source, and fall back to source search if unavailable or incomplete. A self-contained snippet may not need repository exploration. Cite useful code locations, distinguish evidence from inference, and state meaningful uncertainty.
