# Design

Use when: New interfaces or substantial visual or interaction decisions.

Use the audience, task, product brief, and existing design system to choose hierarchy, typography, spacing, content, and responsive behavior. State the consequential choices and their rationale. Cover loading, empty, error, disabled, and recovery states when relevant. Preserve established branding unless change is authorized. Use production components and semantic tokens. Stop when the assigned design decisions and states are specified or implemented with applicable evidence; user performs manual UX acceptance.
