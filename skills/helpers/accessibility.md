# Accessibility

Use when: Changed interactive UI or an explicitly requested accessibility review.

Inspect semantic structure, accessible names, labels, keyboard operation, focus order and visibility, error association, contrast, and reduced-motion behavior where relevant. Reuse established accessible components. Check the actual production interaction and project-required automated accessibility suites. Identify cases automated checks cannot establish. Do not initiate browser walkthroughs or screenshot acceptance without authorization. Stop after the changed interactions and applicable requested review scope are checked.
