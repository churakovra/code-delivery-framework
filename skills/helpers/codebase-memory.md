# Codebase Memory routing

For structural discovery, check the runtime for Codebase Memory MCP. This applies to repository audits and cleanup even without planning or delegation. Simple known-file edits and literal searches need no graph query. Respect user and runtime restrictions.

When available, read the installed integration skill. Select the project by root; check index readiness and freshness, and index or refresh when needed and permitted. Use a relevant graph query before concluding structural investigation. Follow the skill's coverage and pagination guidance, including relevant scopes for negative claims. Verify material findings and coverage gaps in source; graph absence alone does not prove unused code.

If tools are unavailable, indexing fails, or coverage is insufficient, use source search and report the material limitation. Do not claim graph evidence that was not obtained.
