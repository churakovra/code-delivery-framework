# Handoff checklist

- [ ] State changed files and concise behavior/documentation changes.
- [ ] Report only current checks actually run, with exact commands and results.
- [ ] Include required review status and concrete findings.
- [ ] Identify unavailable checks, limitations, and blockers.
- [ ] Give a short user manual-acceptance checklist where applicable.
- [ ] Keep commits, pull requests, merges, releases, and deployment with the user unless explicitly authorized.
